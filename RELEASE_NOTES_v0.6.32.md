# HomeTiles Bridge v0.6.32

Install this update before HomeTiles firmware v0.6.4 and restart Home Assistant.

- Adds Home Assistant support for firmware-defined local switches, onboard
  relays and temperature sensors.
- Migrates generated entity IDs to readable names while preserving manually
  renamed IDs and collision suffixes such as `_2`.
- Keeps MQTT topics, unique IDs and existing firmware compatibility unchanged.

**Full Changelog:** https://github.com/GalusPeres/HomeTiles-Bridge/compare/v0.6.31...v0.6.32
