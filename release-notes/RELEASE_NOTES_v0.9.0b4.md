# HomeTiles Bridge v0.9.0b4 (beta)

Clearer dialog when a panel that is already set up presses Pair.

- The dialog for a panel that already has an entry now fits every case: a panel on MQTT that switches to the direct connection, and a panel on the direct connection that pairs again. Its entry, area, names and entities stay.
- Everything from v0.9.0b3 is unchanged.

Install: in HACS enable "Show beta versions" for HomeTiles Bridge, update, restart Home Assistant and reload the page with Ctrl+Shift+R.

Validation: 530 Bridge tests. Validation in a real Home Assistant installation is in progress.
