# HomeTiles Bridge v0.9.0b15 (beta)

The Home Assistant log shows what a panel receives.

- When a panel tells the Bridge which entities it uses, the log shows one line, for example "HomeTiles panel hometiles_f6e8 declared 40 entities, only its own; it gets 52 entities (61 before)". It appears once after each Home Assistant start and when the panel's tiles change, never repeatedly.
- Everything else from v0.9.0b14 is unchanged.

Install: in HACS enable "Show beta versions" for HomeTiles Bridge, update, restart Home Assistant and reload the page with Ctrl+Shift+R.

Validation: 575 Bridge tests pass.
