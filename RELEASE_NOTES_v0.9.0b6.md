# HomeTiles Bridge v0.9.0b6 (beta)

The "Discovered" card of a panel now ends with its pair window.

- When the two minutes after Pair run out, or pairing is cancelled on the panel, the card disappears from Settings > Devices & services. Before, it stayed and Submit only failed.
- A card whose setup is already running is kept.
- Everything from v0.9.0b5 is unchanged.

Install: in HACS enable "Show beta versions" for HomeTiles Bridge, update, restart Home Assistant and reload the page with Ctrl+Shift+R.

Validation: 539 Bridge tests pass. Validation in a real Home Assistant installation is in progress.
