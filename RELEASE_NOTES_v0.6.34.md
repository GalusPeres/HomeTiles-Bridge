# HomeTiles Bridge v0.6.34

Install this update together with a HomeTiles firmware build that supports Cover
tiles and restart Home Assistant.

- Adds Home Assistant Cover entities to the Bridge configuration.
- Publishes retained Cover state including availability, device class, supported
  features, position and tilt position.
- Validates and forwards Cover open, close, stop, position and tilt commands.
- Keeps existing configurations compatible; selecting Cover entities is optional.

**Full Changelog:** https://github.com/GalusPeres/HomeTiles-Bridge/compare/v0.6.33...v0.6.34
