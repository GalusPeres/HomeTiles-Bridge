# HomeTiles Bridge v0.6.33

Install this update together with the current HomeTiles firmware and restart
Home Assistant.

- Uses one consistent 1-100% MQTT scale for normal display and screensaver
  brightness.
- Keeps the Home Assistant Light and Number controls aligned with each panel's
  device-specific brightness calibration.
- Detects and translates the former 121-255 display-brightness protocol so
  panels with older firmware remain controllable.
