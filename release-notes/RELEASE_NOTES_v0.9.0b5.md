# HomeTiles Bridge v0.9.0b5 (beta)

Pairing without a restart of the panel.

- With matching firmware the panel no longer restarts after Add: it connects within seconds and the number appears. The dialog texts say so.
- A panel that reconnects right after pairing, a moment before its entry exists, is accepted instead of refused.
- Everything from v0.9.0b4 is unchanged.

Install: in HACS enable "Show beta versions" for HomeTiles Bridge, update, restart Home Assistant and reload the page with Ctrl+Shift+R.

Validation: 530 Bridge tests, five full runs without a failure. Validation in a real Home Assistant installation is in progress.
